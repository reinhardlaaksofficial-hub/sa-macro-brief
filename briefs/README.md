# Published briefings

Briefings published automatically by the scheduled watcher
(`.github/workflows/watch.yml`) as Stats SA releases land. Each is a
one-page PDF built from the release's own files, with a footer recording the
source and the retrieval timestamp.

Basic data: Statistics South Africa. Users may apply the information as they
wish, provided they acknowledge Stats SA as the source of the basic data, and
specify that the relevant application and analysis result from their own
processing of the data.
